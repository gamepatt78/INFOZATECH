# Task 3 — Multi-Step Form Wizard

Happy to share my Multi-Step Form Wizard, built as part of my frontend development internship with InfozaTech!

The app guides users through personal details and address information, validates each step, and provides a review screen before showing a submission confirmation. Its progress indicator and responsive layout help make a longer form feel clear and manageable.

This is a frontend demo: submitted information is not sent to a server or saved. In my demo video, I’ll walk through the steps, validation, and review screen.
