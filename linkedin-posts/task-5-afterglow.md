# Task 5 — Afterglow Streaming-Style UI

Introducing Afterglow, my streaming-style browsing interface built as part of my frontend development internship with InfozaTech!

Afterglow lets you browse 22 original fictional stories in responsive carousels, filter by genre, search the collection, open story details, read an original opening-scene preview, and save favorites to My List. The poster-style artwork is created with CSS, and the stories are original demo content.

In my demo video, I’ll explore the collection, open a story preview, and show how My List remembers saved titles.
