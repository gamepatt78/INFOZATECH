## About this collection

This repository is the portfolio index for the projects. Application source code, setup instructions, and deployment configuration are maintained in each linked project repository. The demos are independent and do not share a backend unless their own documentation says otherwise.

## Tech

The projects use a combination of:

- React and Vite
- Responsive CSS and Lucide icons
- Firebase Hosting
- Browser storage for selected demo preferences and board state
- Firebase Authentication in Northstar Store Analytics

## Run a project

Open the project's source repository from the table above and follow its README for requirements, local development, production builds, and deployment. Each app has its own dependencies and Firebase Hosting configuration.

## Notes

- Product Search and Northstar display illustrative public or sample data; see each project's README for data details.
- The Form Wizard is a front-end demonstration and does not send submitted details to a backend.
- The Kanban Board saves board state in the current browser.
- Afterglow uses original fictional stories and CSS-generated poster illustrations.
